# AegisCard - Credit Card Fraud Detection System

## Packages & Libraries

The following libraries and packages are used in this project:

- **pandas** (`>=2.0.0`) - Data loading, manipulation, and analysis
- **numpy** (`>=1.24.0`) - Numerical computations and array operations
- **scikit-learn** (`>=1.2.0`) - Data preprocessing, model training, and evaluation metrics
- **matplotlib** (`>=3.7.0`) - Data visualization and plotting
- **seaborn** (`>=0.12.0`) - Statistical data visualization
- **jupyter** (`>=1.0.0`) - Interactive notebook environment

### Installation

Install all required packages using:

```bash
pip install -r requirements.txt
```
